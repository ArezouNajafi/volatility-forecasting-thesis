# Volatility Forecasting Thesis

## Objective
Forecast stock market volatility in Tehran Stock Exchange using regime-sensitive machine learning models.

## Methods
- Econometric models (GARCH, etc.)
- Machine Learning models (Random Forest, XGBoost)
- Deep Learning (LSTM)
- Regime switching approaches

## Data
- Tehran Stock Exchange index data
- Macroeconomic variables (exchange rate, inflation, oil price, interest rate)

## Tools
Python, Pandas, NumPy, Scikit-learn, PyTorch
